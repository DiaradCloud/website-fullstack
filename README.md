# ☁️ Diarad Cloud

**زیرساخت ابری آزاد و ایرانی برای توسعه‌دهندگان، استارتاپ‌ها و کاربران حرفه‌ای**

Diarad Cloud یک پلتفرم ابری تمام‌ایرانی است که با هدف ارائه‌ی سرویس‌های ابری ارزان‌قیمت، شفاف و مبتنی بر نرم‌افزار آزاد طراحی شده است. این پروژه با تکیه بر بک‌اند قدرتمند ، فرانت‌اند مدرن React و دیتابیس Supabase، به دنبال ایجاد یک اکوسیستم ابری مستقل برای جامعه‌ی فنی ایران است.

---

## ✨ ویژگی‌های کلیدی

- **مدیریت ابرک‌ها**: ایجاد، مدیریت و مقیاس‌پذیری سرورهای مجازی سبک با منابع دلخواه (رم، CPU، فضا)
- **پنل کاربری و ادمین کامل**: رابط کاربری واکنش‌گرا با مدیریت سرویس، پشتیبانی تیکت، آمار و گزارش‌های مالی
- **اینترنت بین‌الملل**: فعال‌سازی اینترنت بین‌الملل با احراز هویت و رعایت حریم خصوصی
- **نرم‌افزار آزاد**: تمام کدها تحت لیسانس GPL منتشر شده و جامعه می‌تواند در توسعه مشارکت کند
- **قفل‌شدن پلن‌ها**: امکان قفل کردن پلن‌ها و دیتاسنترها به‌صورت موقت یا دائمی از پنل ادمین

---

## 🛠️ تکنولوژی‌ها

| بخش | تکنولوژی |
|:---|:---|
| **بک‌اند** | Python (FastAPI) |
| **فرانت‌اند** | React.js + Tailwind CSS |
| **دیتابیس** | PostgreSQL (Supabase) |
| **احراز هویت** | JWT + Supabase Auth |
| **زیرساخت** | قابل دیپلوی روی Vercel و سرورهای اختصاصی |

## 🚀 نصب و اجرا

### پیش‌نیازها

- Node.js 18+

### مراحل نصب

```bash
# ۱. کلون کردن پروژه
git clone https://github.com/DiaradCloud/website-fullstack.git
cd website-fullstack

npm install   #نصب پکیج های لازم و بیلد
npm run dev   # اجرا در محیط آزمایشی
```

### تنظیمات محیطی

یک فایل `.env` در ریشه‌ی پروژه با این مقادیر ایجاد کنید:

```env
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_anon_key
JWT_SECRET=your_jwt_secret
```
